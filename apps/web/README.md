# Justice For All public web

This package is the only Next.js App Router entrypoint (`apps/web/app`).

From the repository root use `corepack pnpm install --no-frozen-lockfile` and `corepack pnpm dev`. No auth, evidence, or application-integration endpoints are enabled yet. Planned source-of-truth and security boundaries are in [docs/ARCHITECTURE.md](../../docs/ARCHITECTURE.md).
